VERSIÓN 1.0.2 · BUILD 4

DashCore

Evolución de la plataforma
✦ Nuevo
  • Experiencia diseñada para pantallas Android: interfaz optimizada para radios y pantallas de vehículos, con elementos grandes, claros y fáciles de visualizar.
  • Visualización 3D de vehículos: integración de modelos 3D reales para representar visualmente el vehículo dentro del dashboard.
  • Conectividad en la nube: DashCore puede recibir información, avisos y novedades de forma remota.
  • Funcionamiento offline: las funciones principales del dashboard pueden utilizarse sin depender de una conexión permanente a Internet.
  • Sistema de actualizaciones: nueva infraestructura para gestionar versiones y novedades de DashCore.
  • Nuevos estilos de dashboard: ampliación de la colección de tableros para ofrecer diferentes experiencias visuales.
  • Estadísticas de conducción: seguimiento de recorridos, distancia, velocidad máxima, tiempo de conducción y viajes realizados.
  • Rangos de conductor: progreso basado en la actividad de conducción y diferentes reconocimientos.
⬆ Mejorado
  • Dashboard: rediseño y mejoras visuales en múltiples estilos de tablero.
  • Experiencia visual: interfaces más modernas, dinámicas y adaptadas al entorno automotriz.
  • Personalización: más posibilidades para adaptar el dashboard al estilo del conductor.
  • Tienda de estilos: navegación más organizada para descubrir y gestionar diferentes diseños.
  • Inicio de DashCore: experiencia de bienvenida más moderna y fluida.
  • Modelos de vehículos: mejoras en la visualización y compatibilidad del contenido de vehículos.
  • Rendimiento: optimizaciones para mejorar la experiencia en diferentes dispositivos Android.
  • Navegación: mejoras generales en la interacción y organización de las diferentes secciones.
✦ Experiencia DashCore
  • Head-Unit First: DashCore está pensado para utilizarse directamente desde la pantalla del vehículo, priorizando visibilidad y facilidad de uso.
  • Datos del vehículo en tiempo real: velocidad, RPM, temperatura y otros parámetros pueden visualizarse mediante OBD2.
  • Dashboard interactivo: elementos visuales diseñados para responder de forma dinámica durante la conducción.
  • Arquitectura híbrida: aplicación Flutter junto con servicios backend para permitir una evolución más rápida de la plataforma.
  • Privacidad: DashCore está diseñado para mantener transparencia sobre los datos que se sincronizan con sus servicios.
✓ Corregido
  • Mejoras generales de estabilidad.
  • Correcciones en la visualización de dashboards y sus elementos.
  • Correcciones en la carga de contenido y recursos.
  • Mejoras en la navegación general de DashCore.
  • Optimización de diferentes componentes para dispositivos Android.
