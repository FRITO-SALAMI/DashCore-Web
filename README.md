# DashCore Web

Official website and landing page for **DashCore**, a modern digital dashboard platform designed for Android automotive displays and multimedia radios.

## 🚗 About DashCore

DashCore transforms compatible Android automotive displays into a customizable digital dashboard experience, combining modern visual design, vehicle telemetry, dashboards and multimedia features.

This repository contains the **DashCore Web** frontend and landing page.

## ✨ Features

* Modern responsive landing page
* DashCore product presentation
* Dashboard previews and visual showcase
* APK download section
* Updates and announcements
* Responsive design for desktop, mobile and tablet
* Admin section for website management
* SEO configuration with `robots.txt` and `sitemap.xml`
* Google Search Console verification
* Vercel-ready deployment configuration

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Vercel
* GitHub

## 🚀 Deployment

The project is designed to be deployed through **Vercel**.

The production website can be automatically updated whenever changes are pushed to the `main` branch.

```bash
git add .
git commit -m "Update website"
git push
```

## 📱 DashCore Android App

The DashCore Android application is maintained separately from this web repository.

Android releases and APK distribution are handled independently from the website.

## 🔐 Security

Do not commit:

* API keys
* Private credentials
* Service account files
* Authentication secrets
* Private configuration files

Public frontend configuration should only contain information intended to be exposed to users.
